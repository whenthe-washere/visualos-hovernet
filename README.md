visualOS HoverNet is an open-source lightweight browser template that uses PySide6.
The browser can also be downloaded as an application for people that only want to use it.
Anyone can fork the code and make tweaks, as long as they have the requirements, aka Python(3.14) and Python libraries such as PySide6, ctypes etc. AND as long as there is any sort of credit to whenthe's space.
